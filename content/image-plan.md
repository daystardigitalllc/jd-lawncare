## 2. Image Performance Specifications
1.  **Format:** Convert all raster images (JPG/PNG) to modern **WebP** format. Use **SVG** for logos and icons.
2.  **Compression:** Run images through compression tools (e.g., TinyPNG or local compressor) before upload. Ensure banner images are under `150KB` and card/portrait images are under `80KB`.
3.  **Filenames:** Use lowercase, hyphen-separated filenames. Avoid generic names like `IMG_9482.jpg`. Use descriptive, keyword-rich names (e.g., `roofing-repair-atlanta-ga.webp`).
